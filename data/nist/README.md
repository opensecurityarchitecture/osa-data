# NIST SP 800-53 Rev 5, as OSA uses it

`sp800-53-rev5.json` holds every control and enhancement of NIST SP 800-53, Release 5.2.0: name, statement, discussion, related controls, baselines, and for a withdrawn control what it was incorporated into.

It is generated by `scripts/build_nist_extract.py` from three things NIST publishes for that release. Their addresses and the hashes of the copies used are in the file under `sources`.

- The CPRT export, for the text as NIST renders it.
- The OSCAL catalogue, for titles and for what was withdrawn.
- The four OSCAL baseline profiles: low, moderate, high and privacy.

Where two of them state the same thing they were compared. The baselines agree for every control and enhancement. The few places where the text differs are listed in the file under `checks`.

Do not edit the file by hand. The control files, the control manifest and the control names in the patterns are kept in step with it by `scripts/sync_nist.py`.
